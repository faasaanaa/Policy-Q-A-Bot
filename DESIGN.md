# NovaCart interface

Mode: Operate, with source reading as a secondary task. The user delegated the replacement direction.

Use a compact reference desk: a quiet navigation rail, a conversation sized to the viewport, and a source sheet opened on demand. White and cool slate surfaces, blue actions, navy text; a separate dark theme uses the same hierarchy. The user subsequently requested a more expressive dashboard: a navy welcome panel with animated geometric Nova artwork, an activity band, real-data chart, and recent events. Counts are device-local and start at zero, never seeded with illustrative activity. The chat retains its compact layout.

Body text 14–15px, controls 13px, metadata 12px. Consistent 8px spacing rhythm and 12px main panel corners. One thread scroll area in chat, normal page scrolling in tools, no scrollbars inside answer text. Long answers expand in place. Only the current clarification has an editable form. Respect reading position, keyboard focus, RTL languages, and reduced motion.

The reference-desk direction takes consistent alignment and typographic discipline from the design-annual challenger, clear wayfinding from the guide-map challenger, and configurable density from the specimen challenger without borrowing their decorative motifs. The user's request for compact, readable task UI controls the result. Code-led implementation uses native controls and authored geometric SVG; no raster assets are needed.

Validation is through source inspection, automated checks, and HTTP only: the user explicitly prohibits computer use, so browser visual verification is unperformed.
